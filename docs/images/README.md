# docs/images

Store reusable question and teaching images here.

In **Edit Images**, upload files with the file picker, drag/drop, or paste from your
clipboard by clicking the target upload area and pressing Ctrl/⌘+V. You can also use
Copy/Paste buttons on attached images to duplicate an image between slots or cells.

Use the **Image size** slider in each preview to scale how large the image appears
when the question or teaching pearl is shown.

Uploaded and pasted images are saved in your browser local storage, so they remain
after refresh on the same browser/device.
