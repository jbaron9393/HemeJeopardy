# docs/images

Store reusable question and teaching images here.

In **Edit Images**, upload files with the file picker, drag/drop, or paste from your
clipboard by clicking the target upload area and pressing Ctrl/⌘+V. You can also use
Copy/Paste buttons on attached images to duplicate an image between slots or cells.

Use the **Quick Text Edits** fields to update the category name, question, answer,
or teaching pearl while you are in the same editor. Use the **Image size** slider in
each preview to scale how large the image appears when the question or teaching pearl
is shown.

To keep `index.html` small enough to edit directly in GitHub, the old embedded
Base64 starter images were removed. Add replacement image files to this folder or
use the in-browser upload/paste controls to attach them to cells.

Uploaded and pasted images are saved in your browser local storage, so they remain
after refresh on the same browser/device.
